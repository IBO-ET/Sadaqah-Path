# صدقة — Sadaqah Path 2.1.2 — Windows Desktop

الإصدار المستقر الأول لنسخة الكمبيوتر من Sadaqah Path.

## المميزات

- مواقيت الفجر والظهر والعصر والمغرب والعشاء حسب المدينة والدولة.
- الصلاة القادمة والعد التنازلي.
- أذان تلقائي عند دخول الوقت.
- خلفية طبيعة عبر YouTube ويمكن تغيير الرابط من الإعدادات.
- قرآن كريم كامل للعمل Offline بعد تجهيزه أثناء البناء.
- 114 سورة، بحث داخل القرآن، وحفظ آخر موضع قراءة.
- تغيير حجم خط القرآن.
- اختبار صوت الأذان من الإعدادات.
- حفظ الإعدادات محليًا على الجهاز.
- F11 للشاشة الكاملة و Esc للخروج.
- بدون إعلانات أو اشتراكات أو حساب مستخدم.
- لا تستخدم نسخة الكمبيوتر الموقع الجغرافي ولا تحتوي على القبلة.
- Windows 64-bit و32-bit.

## بناء النسخة النهائية

1. فك ضغط المشروع.
2. شغّل `Build-Windows-EXE.cmd`.
3. يحتاج البناء للإنترنت في المرة الأولى لتنزيل Node packages ونص القرآن من المصدر الرسمي.
4. الملفات النهائية تظهر داخل `dist`:

- `Sadaqah-Path-2.1.2-Windows-x64.exe`
- `Sadaqah-Path-2.1.2-Windows-ia32.exe`

بعد بناء التطبيق، القرآن يعمل Offline. مواقيت الصلاة وفيديو الخلفية والأذان الحالي تحتاج اتصالًا بالإنترنت، مع حفظ مواقيت اليوم الصحيحة كنسخة احتياطية عند توفرها.
