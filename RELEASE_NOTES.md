# Sadaqah Path 2.1.2 — Windows Stable

First public stable Windows release of Sadaqah Path.

## Included
- Prayer times and next-prayer countdown
- Automatic Adhan
- Offline Quran text
- Quran search and saved reading position
- Adjustable Quran font size
- Arabic, German and English interface
- Windows 64-bit and 32-bit support
- Multilingual installer
- No ads, subscriptions or account

## Download
Download only:

`Sadaqah-Path-2.1.2-Setup.exe`

## Notes
Internet is required for current prayer-time retrieval, the YouTube nature background, and streamed Adhan audio. Quran text works offline after installation.
